# 文档解析

厂商资料 80% 是 PDF，且核心数据全在**表格**里。解析丢表格 = 整条数据废掉。

## 一、按格式选库

| 格式 | 库 | 要点 |
| --- | --- | --- |
| PDF | `pypdf` | 纯 Python、无系统依赖；`extract_text()` 逐页取 |
| PDF（表格多） | `pymupdf` | 表格还原更好，但体积大，只在必要时换 |
| DOCX | `python-docx` | 段落 **和** `document.tables` 都要取 |
| XLSX | `openpyxl`（`data_only=True`） | 读公式结果值，不读公式 |
| HTML | `beautifulsoup4` | 先删 `script/style`，再 `get_text("\n")` |
| MD/TXT/CSV | 内置 | 编码按 `utf-8 → gbk` 顺序尝试 |

## 二、四条硬规则

1. **保留页码**：每个片段带 `page`，最终写进来源，用户能翻回原文核对。
2. **表格转文本要带表头**：每行输出 `列名: 值`，而不是裸值。裸值无法理解。
3. **不拼接跨页表格**：宁可多一条记录，也不要错误合并两页的不同产品。
4. **空页不报错**：扫描版 PDF 抽不出文字是常态，跳过并计数，不要抛异常中断整批。

## 三、解析产物格式

统一成：

```python
{"file": "daikin_ffkm.pdf", "pages": [{"page": 3, "text": "..."}], "warnings": ["第 7 页无文本层"]}
```

下游分块、抽取都以 `pages` 为单位，页码自然带下去。

## 四、高频故障

| 现象 | 原因 |
| --- | --- |
| 全角乱码、问号方框 | PDF 字体未嵌入，只能换 `pymupdf` 或人工介入 |
| 表格读成一行到底 | 用了 `extract_text()` 的默认模式，缺分隔符 |
| DOCX 只有正文没表格 | 只遍历了 `paragraphs`，漏了 `tables` |
| XLSX 全是 `None` | 忘了 `data_only=True`，读到的是公式单元格 |
| 中文变 `æ•°æ®` | 用 utf-8 解 gbk 文件，改成 try 链式解码 |

## 五、自检

- [ ] 随机抽 2 页，人工对比原文与解析文本
- [ ] 表格是否每行都带列名
- [ ] 每条片段是否带页码
- [ ] 扫描版 PDF 是否被跳过而不是崩掉
- [ ] 解析耗时是否被记录（>5 秒的文件要单独看）
