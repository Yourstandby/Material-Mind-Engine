## 二、30 秒验证通不通

### 方式 A：cmd 窗口里用 curl（最省事）

按 `Win+R` → `cmd` → 回车，粘贴下面两行：

```bat
curl.exe http://172.16.1.210:8100/v1/models -H "Authorization: Bearer mme-xxxxxxxx"

curl.exe http://172.16.1.210:8100/v1/chat/completions -H "Authorization: Bearer mme-xxxxxxxx" -H "Content-Type: application/json" -d "{\"model\":\"qwen3-30b\",\"messages\":[{\"role\":\"user\",\"content\":\"hi\"}]}"
```

第一条返回里能看到下面这段就算通了（其余字段可忽略）：

```json
{"object":"list","data":[{"id":"qwen3-30b","object":"model","owned_by":"llamacpp"}]}
```

第二条返回 `choices[0].message.content`，就是模型的回答。

### 方式 B：PowerShell

> ⚠️ PowerShell 里 **不要**用 `curl.exe -d "{...}"`：PS 5.1 会把引号吃掉，服务端报
> `json.exception.parse_error`。用 `Invoke-RestMethod` 拼 JSON：

```powershell
$h = @{ Authorization = "Bearer mme-xxxxxxxx" }
$b = @{ model = "qwen3-30b"; messages = @(@{ role = "user"; content = "hi" }) } | ConvertTo-Json -Depth 5
(Invoke-RestMethod "http://172.16.1.210:8100/v1/chat/completions" -Method Post -Headers $h -ContentType "application/json" -Body $b).choices[0].message.content
```

> PowerShell 5.1 处理中文有编码坑（请求体、响应解码两边都可能乱码）。
> **中文场景请用下面的 Python 示例**，别在 PowerShell 里折腾。

### 方式 C：Python（推荐，中文没问题）

```python
import urllib.request, json

body = json.dumps({
    "model": "qwen3-30b",
    "messages": [{"role": "user", "content": "用一句话介绍氟橡胶"}],
}).encode("utf-8")

req = urllib.request.Request(
    "http://172.16.1.210:8100/v1/chat/completions",
    data=body,
    headers={"Content-Type": "application/json",
             "Authorization": "Bearer mme-xxxxxxxx"},
)
print(json.load(urllib.request.urlopen(req, timeout=120))["choices"][0]["message"]["content"])
```

## 三、接进你的项目

### Python（最常用）

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://172.16.1.210:8100/v1",
    api_key="mme-xxxxxxxx",
)

# 对话
resp = client.chat.completions.create(
    model="qwen3-30b",
    messages=[{"role": "user", "content": "FFKM 和 FKM 有什么区别？"}],
)
print(resp.choices[0].message.content)

# 向量（1024 维）
vec = client.embeddings.create(
    model="bge-m3",
    input=["全氟醚橡胶 耐高温 230℃"],
).data[0].embedding
```

流式（边生成边显示）：

```python
for chunk in client.chat.completions.create(
    model="qwen3-30b",
    messages=[{"role": "user", "content": "写一段材料简介"}],
    stream=True,
):
    print(chunk.choices[0].delta.content or "", end="")
```

返回：

  "elapsed_ms": 2130

支持 png / jpg / tif / bmp / webp。A4 扫描页约 2–4 秒。

## 五、常见问题

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 连接超时 | 不在同一网段，或服务器防火墙没放行 | 确认能访问 `172.16.1.210`，ping 一下 |
| `401 Unauthorized` | Key 错、已失效，或少了 `Bearer ` 前缀 | 检查 Key，注意 `Authorization: Bearer xxx` 中间一个空格 |
| `429 并发超限` | 同一个 Key 同时发起的请求太多（默认最多 2 个） | 排队串行发；确实需要更高并发就申请单独 Key |
| `429`（另一个原因） | 超过每分钟请求数上限 | 降低频率，或申请调大配额 |
| `404 model not found` | 模型名写错 | 用 `/v1/models` 返回的名字 |
| 建库时报维度不匹配 | embedding 维度没填 1024 | 填 1024 |
| PowerShell 里中文乱码 / `json.exception.parse_error` | PS 5.1 的引号与编码问题 | 用 Python 示例，或改在 `cmd` 里跑 curl |

2. **不要把地址和 Key 写进对外发布的产品**（这是内网服务）。
3. **批量任务请错峰**：单个任务动辄几百次调用，尽量放在下班后跑，白天优先保证大家正常问答。
4. **单次上下文 64K token**（约 4 万汉字）。长文档请先切块，不要整篇塞进去。
5. 这是台真机器上的本地模型，**单路约 11–16 tok/s**，生成 300 字大约 20–30 秒，属正常。
